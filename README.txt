Vibe Homepage - 我的数据小馆
===========================

用途
----
这是作业三「用 Vibe Coding 打造我的数据小馆个人主页」的独立基础版。
它适合连接到一个新的 GitHub 仓库，例如 vibe_homepage，并通过 GitHub Pages 发布为项目站点。

本地预览
--------
直接双击 index.html 即可打开。
也可以在本目录运行：
python -m http.server 4174

需要先替换的内容
----------------
1. 打开 content.js，替换昵称、专业、年级、简介和标签。
2. 将 data.entries 改成真实属于你的小数据。
3. 将 assets/avatar-placeholder.svg 替换成能代表你的图片。
4. 修改 egg.moods，让互动彩蛋更像你自己的原创梗。

作业要求对应
------------
- 自我介绍区：顶部 hero + 馆主头像卡片。
- 数据可视化区：中部柱状图 + 数据观察。
- 交互彩蛋：头像旁按钮抽吐槽、夜间模式、心情拉杆隐藏饮品和高能量印章。
